基于手势识别的智能系统 v1.0.0 —— 本地使用说明
==================================================
说明：此文件是具体的使用说明，不是 README.md，也不是开源协议。

一、项目位置
  C:\Users\jack\Desktop\niit\计算机视觉\基于手势识别的智能系统
  工程可以放在任何不含特殊权限限制的位置；所有 Python 路径使用项目相对路径。
  建议在已配置的开发环境（如 Win11-Dev 虚拟机）中执行，摄像头需要能透传或直接连接到该系统。

二、准备
  1. 建议 Windows 11 + Python 3.10~3.14，内置或 USB 摄像头。
  2. PowerShell 从项目目录运行：
       powershell -NoProfile -ExecutionPolicy Bypass -File ".\工具\首次安装.ps1"
  3. 不需要全局安装 Python 包：脚本创建本项目 .venv，并默认使用 PyTorch CPU 版。
     如果 Python 不在常见位置，先通过 py -0p 查看已安装版本。
  4. 检查环境：
       .\.venv\Scripts\python.exe 检查环境.py
  5. 先体验界面（此时尚不能识别手势）：
       .\.venv\Scripts\python.exe 启动系统.py

三、采集训练数据——本作业必须完成的部分
  六个类别：张开手掌、握拳、点赞、剪刀手、食指指向、无手。
  建议每类别至少 5 个独立采集轮次，每轮约 80~150 张。
  轮次之间换光照、背景、日期或时段；手势在固定中央方框中。
  每轮拍摄时适当改变手的大小、角度和方位，但保持完整静态手势。
  “无手”要采不同背景、衣服、桌面等负样本，但不要故意把手留在框边缘。
  每轮运行一条命令，依次对六个类别按提示按 S 开始/暂停拍摄，Q 取消。
       .\.venv\Scripts\python.exe 采集数据.py --all --session 场景01 --count 100
       .\.venv\Scripts\python.exe 采集数据.py --all --session 场景02 --count 100
       .\.venv\Scripts\python.exe 采集数据.py --all --session 场景03 --count 100
       .\.venv\Scripts\python.exe 采集数据.py --all --session 场景04 --count 100
       .\.venv\Scripts\python.exe 采集数据.py --all --session 场景05 --count 100
  不能把一个视频切成五段，冒充独立背景/时段采集轮次。
  采集时 Ctrl+C 或 Q 中断后会保留已写入图片。若轮次不完整，手动确认并决定是否删除该轮、重新采集。
  数据保存：数据/类别名/采集轮次/*.jpg；数据目录默认不会上传 GitHub。
  注意镜像一致性：采集端与实时推理端都在显示之前做了左右镜像。

四、训练自己的 CNN
  默认在 CPU 训练两个可比较的模型：
       .\.venv\Scripts\python.exe 训练模型.py --epochs 12 --device cpu
  如确实另外配置了兼容 CUDA 的 PyTorch，也可以手工改为 --device cuda。
  每次训练固定按“采集轮次”划分训练/验证/测试，禁用相邻帧跨集混合。
  方案 A：基线轻量卷积网络，无增强。
  方案 B：相同网络 + 轻微角度/亮度/对比度增强（不做左右翻转）。
  依据验证宏平均 F1/准确率选正式模型、验证阈值，再检查两者独立测试结果。
  所有生成权重在“模型”文件夹：正式模型.pt、基线模型.pt、改进模型.pt。
  “输出/实验分析”包含曲线、混淆矩阵、逐类指标、训练历史和报告草稿。
  有测试结果不等于真实世界都有效；“未知手势”不存在严格保证。

五、重新评估
       .\.venv\Scripts\python.exe 评估模型.py --model 正式
       .\.venv\Scripts\python.exe 评估模型.py --model 基线
       .\.venv\Scripts\python.exe 评估模型.py --model 改进
  从保存的“模型/数据划分.json”读取完全相同的独立测试集。
  阈值最初根据验证集调整；如果修改“设置.json”的“最小置信度”（默认 null），
  则实时界面使用你填写的阈值覆盖训练结果；改动需要另行记录验证效果。

六、实时演示
       .\.venv\Scripts\python.exe 启动系统.py
  主界面左侧：真实摄像头 ROI、识别类别、置信度、FPS、推理耗时和系统状态。
  主界面右侧：图片浏览；将个人照片放进“素材/图片”可代替内置演示素材。
  张开手掌=下一张，握拳=上一张，点赞=放大，剪刀手=缩小，食指指向=暂停/恢复。
  无手、低置信度、摄像头错误不会执行控制指令。
  控制防抖：稳定若干帧后仅触发一次，移开到无手/低置信度区域数帧后重新解锁。
  暂停时只允许使用食指指向恢复手势控制；按钮/键盘是始终保留的人工操作入口。
  快捷键：左右箭头切图、+/− 缩放、空格暂停/恢复、Esc 退出。

  运行时会自动产生“输出/真实摄像头运行日志/*.csv”，仅有分类、置信度、FPS 等统计，
  不保存摄像头视频或画面；可据此统计运行状态和采集现场实验结果。

七、项目测试
       .\.venv\Scripts\python.exe -m unittest discover -s 测试 -p "test_*.py" -v
  验证轮次隔离、像素预处理、阈值、控制门控、暂停逻辑。
  现场测试时请逐项记录：FPS、推理耗时、混淆类别、无手识别、光照变化、恢复/退出。

八、GitHub 初始化与发布（需安装 Git + GitHub CLI，首次需要 gh auth login）
  切换到本项目 PowerShell 后执行：
       powershell -NoProfile -ExecutionPolicy Bypass -File ".\工具\初始化并发布1.0.0.ps1"
  该脚本检查绑定账号 nljie1103、Private 隐私、main、Commit、v1.0.0 Tag、Release 和源码包。
  过程中要求输入 YES 确认将所列文件提交到私人仓库；避免意外提交。
  如果依赖没装好，可以先推源码；训练数据和模型可在后面继续本地制作。
  真正训练完成后，可把真实权重及评估结果以 Release 附件上传一次：
       powershell -NoProfile -ExecutionPolicy Bypass -File ".\工具\上传已训练模型.ps1"
  后续每个版本先写中文发布说明，例如“文档/发布说明-1.0.1.txt”，再执行：
       powershell -NoProfile -ExecutionPolicy Bypass -File ".\工具\发布新版本.ps1" -Version 1.0.1 -NotesFile "文档/发布说明-1.0.1.txt"
  该脚本更新版本元数据、提交改动、创建新 Tag、发布新 Release，不覆盖旧版本。

九、真实性与安全
  当前安装包不包含任何真实手势数据或已训练好的手势模型，不能声称已经达到特定准确率。
  使用自己的照片采集、实测准确率和 FPS 后，才可填写正式实验报告。
  未经同意不要采集他人的可识别图像，也不要上传私密图片。
  第三方库：PyTorch、OpenCV、Pillow、NumPy、Matplotlib；请在正式报告中注明。
  后续若准备公开发布仓库，再单独决定适当的许可证。
