Gesture Studio v2.1.0 — 当前版本使用说明
========================================
软件：Python 3.14 / PySide6 / OpenCV / PyTorch，六分类手势识别。

安装 / 启动：
  首次安装：PowerShell 执行 .\工具\首次安装.ps1
  运行：.\.venv\Scripts\python.exe 启动系统.py
  项目可放在其他目录，无需依赖固定路径。

页面： 首页 / 数据 / 训练 / 模型 / 设置。
  摄像头在后台线程采集与识别；主线程仅更新 GUI。
  图片浏览通过独立「图片交互窗口」开启，手势动作才能操控照片。
  数据与训练记录存储在本地，模型、照片和设置不会自动上传。

手势类别：张开手掌、握拳、点赞、剪刀手、食指指向、无手。
手势指令：下一张 / 上一张 / 放大 / 缩小 / 暂停或恢复 / 无手不触发。
模型重新训练后旧阈值不再自动沿用；训练模型与来源记录支持故障恢复。

本地配置：设置.json（可从 设置.example.json 复制初始化；不应提交 Git）。
  应用读取旧设置时只在内存中更新“版本”为当前版本，保存设置时才持久化。
  所有可见运行版本统一来自 手势系统/版本.py。
  历史训练报告中的版本号代表当时生成报告的版本，不能改写旧实验记录。

公开训练数据：数据/公开训练（389 张 HaGRID 裁剪图，五类），
  数据/公开数据清单.json，以及 文档/公开数据来源与授权说明.txt。
  自采轮次放在 数据/<类别>/场景XX/；私人图片禁止上传。

开发者测试：
  .\.venv\Scripts\python.exe -m unittest discover -s 测试 -p 'test_*.py' -v

版本发布：每次单独 Commit、附注 Tag、GitHub Release 和源码 ZIP。
  当前 main 只保留运行/训练需要的代码、测试、公开数据、来源声明和当前说明。
  历史发布脚本与旧版说明保存在对应 Git Tag/Release，不从历史中抹除。
  仓库 Public 由用户主动设置；不要使用强制推送或一键上传全部本机文件。
