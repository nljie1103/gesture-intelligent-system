Gesture Studio v2.0.0 · 全局稳定性与交互修复

兼容当前 v1.7.1 的五页工作台；保留用户现有模型、公开训练数据、私人采集数据和个人设置。

1. 手势暂停：摄像头与推理继续工作，但暂停期间只有食指指向可恢复，其他命令不执行；手动停止与手势暂停分离。
2. 模型训练事务：训练模型和来源记录先校验，再按日志事务发布，发生写入异常时自动恢复旧模型、记录和阈值；进程中断后的待提交事务可在下次加载模型时恢复。
3. 阈值安全：仅在运行阈值的模型 SHA256 与当前模型一致时使用它；新模型产生后使旧阈值失效。设置页手工输入的阈值仍按用户明确选择应用。
4. 相机后台线程：VideoCapture/read、OpenCV 处理和 PyTorch CNN 推理迁至 QThread，按窗口接收确认发送新画面避免 UI 事件队列无限堆积；采集窗口也改用后台读帧。
5. 真实图片指令：按需打开独立图片交互窗口，选择本地图片目录后，手势真实执行下一张/上一张/放大/缩小；未打开时只提示检测到了指令，不假称成功执行。不在首页重新增加图片浏览面板。
6. 异常图像：拒绝不合理超大文件/像素数、符号链接及 Pillow 安全异常，不允许恶意 PNG 造成导入中断。
7. 训练数据稳定：训练先复制所有样本到临时数据快照，防止训练过程中原始图片被移动；窗口训练时禁用采集、导入与回收。
8. 版本号及刷新参数：标题/侧栏/设置一致显示 2.0.0；视频刷新采用合法的 20~1000ms 用户配置，不再暗中强制 >=35ms。
9. 增加了事务故障注入、断电恢复模拟、阈值绑定、坏图、快照与暂停恢复回归测试。

注意：仍未建立独立测试集，训练准确率不是实际识别准确率。首次安装后请在 Win11-Dev 真正运行摄像头、图片操作、采集、1 轮训练，并验证线程退出和窗口关闭。当前开发环境无 Windows 摄像头/PySide6 图形窗口，不声称已通过这些实机测试。
