v1.5.0 · 桌面界面质量修复（基于 v1.4.0）

这次只更新 Qt 桌面界面，不改六分类 CNN、公开训练数据、私人场景图片或模型权重。

修复内容：
1. 窗口真实圆角：根窗口保持逐像素透明，先清除 RGBA 画布再在圆角路径内绘制。Windows DWM 整窗背景从 Acrylic 改为 NONE（避免背景溢出成底部白色方块）；请求系统圆角偏好。注意 Windows 平台与驱动差异仍需实机核验。
2. 左侧导航：用平滑宽度属性动画替代立即 setFixedWidth；在动画结束后才显示导航文字，减少重复布局；期间跳过少量 CPU 摄像头推理帧避免动画卡顿。
3. 按钮规范：标准控件统一最小高度，主按钮采用一致尺寸；不再把部分按钮设计成缩小文本的特殊例外。
4. 导航图标：统一同一套线性 SVG 图标及像素比例；选中态由颜色标识，而非杂糅 emoji / 文本符号。
5. 训练按钮：为“一键训练全部”和“专项强化所选手势”设置可随实际字体计算的最小宽度，避免中文被截断。
6. 下拉框：统一 QComboBox 输入高度、绘制下拉箭头，并独立设置列表行距、选中高亮、圆角与配色。

未改变：
- 五个功能页面：首页、数据、训练、模型、设置。
- 已有采集、自定义快捷键、图片导入/监视、训练全部与专项强化功能。
- 已有 6 个真实分类类别及 4 个尚未训练的预留素材。
- 数据目录 / 模型目录 / 输出目录 / 设置.json；这些都不在更新包里。

验证说明：
- 语法、26 项原有 Python 单元测试，以及 v1.5 新增静态回归测试。
- 本打包环境无法安装 PySide6，未能做真实 Windows 图形渲染及 VMware 摄像头测试。请在 Win11-Dev 现场验收窗口四角、缩放、侧栏动画、下拉框与训练按钮。
- 发布 GitHub 前应运行真实界面；此更新包不会自动推送仓库。
