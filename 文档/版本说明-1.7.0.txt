Gesture Studio v1.7.0 · 训练日志 UTF-8 乱码修复

修复背景：Windows 中文环境中的 Python 训练子进程可能将中文标准输出编码为 GBK/CP936，而 Qt 原界面将管道字节直接作为 UTF-8 解码，因而乱码。此外 QProcess 的分块读取可能将一个多字节汉字拆开。

改动：
1. 仅为训练 QProcess 指定 PYTHONIOENCODING=utf-8 与 PYTHONUTF8=1，不修改系统级环境变量。
2. 使用 Python codecs 增量 UTF-8 解码器，缓存跨 Qt readyRead 回调的残留字节，进程结束时刷新。
3. 每次训练独立初始化解码器；保留标准输出和标准错误合并展示，保持即时训练进度。
4. 新增 7 项专项回归测试，包括强制非 UTF-8 初始环境中的中文子进程输出。
5. 仅改日志处理和界面版本展示，不变更训练算法、数据或模型权重。

注意：升级不能恢复之前已被错误解码的旧界面日志；重新启动一次训练后，新输出应正常显示。若第三方本地程序无视 PYTHONIOENCODING 输出原始 GBK 字节，其文本仍有可能出现替换符号，需要提供原始输出进一步定位。
