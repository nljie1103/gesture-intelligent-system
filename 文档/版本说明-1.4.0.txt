Gesture Studio v1.4.0（待 Windows 实机验收，尚未发布 GitHub）

1. 用 PySide6 完整替换 Tkinter 应用界面。原有 CNN、训练数据目录、权重格式保持。
2. 无边框 Windows 窗口，左上角红/黄/绿交通灯控制，支持窗口拖动、最大化和还原。
   这是 macOS 风格设计，系统材质使用 Windows Acrylic 尝试，并不是 Apple 原生 Liquid Glass。
   某些 Windows 设置、VMware 3D 加速关闭时，系统半透明效果会减弱。
3. 左侧默认折叠，统一五页：首页、数据、训练、模型、设置。
4. 数据页：实时扫描图片；导入单张或文件夹、SHA256 查重、显示各类/公开/私人场景数量。
   可清空选中场景或所有私人采集数据，但只移动到 数据/回收站；不删除公开训练图。
5. 训练页：摄像头采集，允许设置手势类别、起始场景名、场景数量、每秒图片数、
   每类采样数、开始键和停止键。每组拍完要求人工确认下一组动作姿态。
6. 一键训练全部六类、专项强化现有某一个类别（带其他类别重放，避免遗忘）。
   训练在独立子进程运行；旧模型保存在 模型/历史版本；训练失败不替换旧模型。
7. 不展示虚假的测试准确率；场景01训练仍然只属于演示训练，正式实验需要独立数据划分。
8. 手工将图片复制到 数据/<类别>/<场景> 后，数据页在2秒内重新统计；
   其中公开数据不接受通过数据页直接覆盖，避免训练许可和来源清单混乱。

安装依赖：PySide6>=6.10,<6.13，支持 Python 3.14。
验证范围：当前开发环境没有 PySide6 和 Windows GUI，暂未实机执行窗口和摄像头测试。
建议通过安装脚本保留旧版文件并在 Win11-Dev 测试后再发布。
