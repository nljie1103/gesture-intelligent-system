Gesture Studio v2.3.2 · Windows 安装与设置界面修复

1. 原程序运行时不再直接 pip install MediaPipe。先在界面后台下载并缓存组件与模型，随后关闭主程序、等待 Python 进程退出，才在独立进程中替换 OpenCV 文件；安装后自动重启。
2. 将 OpenCV 依赖约束在 4.x，防止 pip 自动升级到不兼容的 5.x；移除冲突的 opencv-python 变体，并在失败时尝试恢复 OpenCV。
3. 修复设置页 QLabel 与 QLineEdit 跨行网格在低窗口高度、Windows 缩放比例下重叠的问题。识别设置与组件安装区分卡片，并允许滚动。
4. 安装完整日志写入 .发布/手部组件最近安装.log。手部组件仍为可选，旧模型及私人图片不修改，不会自动重新训练。
5. Windows 用户需在实际设备上验证独立安装与摄像头，回归测试不能替代系统级验证。
