Gesture Studio v2.3.0：公开数据可选、手部关键点定位实验

一、公开训练数据
1. 工作台训练默认不包含 HaGRID 公开数据；仅用户勾选后加入当次训练。
2. 数据页新增“下载并导入公开数据”，点击并确认后才会从 Hugging Face 官方仓库下载约 402 MB 的原始 ZIP；在下载完成后验证上游公布的 SHA256，随后只导入所需五类裁剪照片。
3. 支持从本地 ZIP 导入，在后台线程解析，避免界面卡住。已有公开数据不重复下载、不覆盖、不删除。
4. 注意：如果启用了“继续旧模型”，即使本轮未选择公开数据，也可能保留历史权重中从公开数据学习的特征。必须勾选“从零训练”，才能排除旧权重的继承。

二、摄像头采集与手部定位
1. 保留旧的固定绿框采集和六分类模型，兼容旧模型与旧照片。
2. 增加可选 MediaPipe Hand Landmarker 模式；安装组件必须在设置页面主动点击，软件安装不自动下载 MediaPipe 或 Google 手部模型。
3. 采集时，正类图片仅在检测到手部时保存手部附近区域；“无手”类别检测到手时跳过该帧；真实手部定位框为红色。
4. 从零训练时可选择“手部关键点裁剪”：读取旧采集图时先定位并归一化手部，已经在此模式采集的图片不再二次裁剪。无手类保留背景。
5. 模型检查点记录输入策略。实时预测按模型策略选择固定区域或手部关键点定位；没有检测到手时报告“无手”。不能把旧固定区域模型直接当成手部裁剪模型。
6. 注意：关键点模型不是手势分类器；“手掌/握拳/点赞/剪刀手/食指”等仍由本项目 CNN 分类，检测误差仍可影响最终结果。

三、保护
训练会保存来源元数据和初始化模型来源，模型旧权重继续备份；更新程序不会覆盖用户设置、照片、手部 .task 文件或训练权重。不自动推送 GitHub。

四、运行条件
手部模式属于实验性功能，依赖 Windows Python 中的 mediapipe 与用户点击下载安装的约 8 MB 官方手部定位 .task 资源。当前容器没有 Windows Qt 摄像头/MediaPipe 组件，须本机验证定位速度、误检和漏检。建议先少量采集试验，不要直接用全部历史数据重训。

公开数据来源：https://huggingface.co/datasets/GestureDetectionConnoisseurs/hagrid_subsets
手部定位文档：https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/python
